# NebulonMind – Project File Reference

## Overview

**NebulonMind** is a memory layer for AI assistants built on top of **NebulonDB**. It stores facts as *Memory Objects* across three representations:

- **Truth** – traditional document store (COSMOS corpus)
- **Meaning** – vector store with embeddings (ORBIT corpus `mind_semantic`)
- **Relationships** – graph store (ORBIT Mesh)

The project is organized into several logical layers:

| Layer | Purpose |
|---|---|
| **Core** (`nmd_host/core/`) | Data models, configuration, repository protocol, the `NebulonMind` facade |
| **Stores** (`nmd_host/stores/`) | API‑backed wrappers for truth, vector, and graph persistence |
| **API** (`nmd_host/api/`) | FastAPI service (port 9696) exposing NebulonMind endpoints |
| **Agents** (`nmd_host/agent/`) | Agent session management, durable storage, background scheduler |
| **Intelligence** (`nmd_host/intelligence/`) | Rule‑based and LLM‑based extraction, decision engine, lifecycle |
| **Lifecycle** (`nmd_host/lifecycle/`) | Retention, deduplication, ranking, retrieval, consolidation, forgetting |
| **Tests** (`tests/`) | Offline and live (e2e) test suites |
| **Scripts** (`scripts/`) | Helper scripts for development / deployment |
| **Docs** (`docs/`) | Design documents, integration guides, architecture diagrams |

*All live e2e tests require a running NebulonDB instance on `localhost:6969` (the default from `.env`). Offline tests (excluding the e2e files) run without a DB and total 398 passed.*

## 7. Quick‑Start Commands

```bash
# 1. Install the package (poetry / pip)
pip install -e .   # or use the provided venv

# 2. Ensure NebulonDB is running (port 6969) and .env is correct

# 3. Start the service
python nebulonmind.py start   # managed runner (PID file + logs; banner, __pycache__ clear)
# or directly:
python -m nmd_host.tui.serve  # or: uvicorn nmd_host.api.server:create_app --port 9696

# 4. Quick sanity check
curl -s http://127.0.0.1:9696/api/NebulonMind/health
# => {"success": true, "data": {...}}

# 5. Run the offline test suite (no DB needed)
python -m pytest -q --ignore=tests/test_e2e.py --ignore=tests/test_api_e2e.py \
    --ignore=tests/test_lifecycle_e2e.py --ignore=tests/test_intelligence_e2e.py \
    --ignore=tests/test_stores.py --ignore=tests/test_repository.py

# 6. Run the full live suite (requires DB)
python -m pytest -q
```
